# Azure Static Website

A static website deployed using Microsoft Azure Blob Storage Static Website hosting.

## Live Website

[View the live Azure website](https://hellenacloudstorage01.z38.web.core.windows.net/)

## Project Overview

This project demonstrates how to host a static HTML and CSS website using Microsoft Azure Blob Storage.

## Technologies Used

- Microsoft Azure
- Azure Blob Storage
- HTML
- CSS

## What I Did

- Created and configured an Azure Storage Account.
- Created a Blob Storage container for project files.
- Enabled Static Website hosting.
- Created and uploaded HTML and CSS files.
- Configured the website index and error documents.
- Verified the website through the Azure Static Website endpoint.
- Used a read-only SAS URL for controlled temporary access to a blob.
